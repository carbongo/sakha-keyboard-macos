Sakha keyboard layouts for macOS
https://github.com/carbongo/sakha-keyboard-macos

INSTALL
Double-click "Install Sakha Keyboard.command" and pick your layouts.
No restart or logout needed.

If macOS says it can't verify the developer:
  1. Click Done (or Cancel).
  2. Open System Settings → Privacy & Security, scroll down, click "Open Anyway".
  3. Double-click the installer again.

This warning is normal for free, unnotarised software. Nothing was found
in the file; macOS shows it for every downloaded script that Apple hasn't notarised.

UNINSTALL
Double-click "Uninstall Sakha Keyboard.command". It needs the same
"Open Anyway" step once.

SWITCHING
Ctrl+Space or the Globe (🌐) key, or the input menu in the menu bar.

Раскладки саха для macOS

УСТАНОВКА
Дважды щёлкните «Install Sakha Keyboard.command» и выберите раскладки.
Перезагрузка и выход из системы не нужны.

Если macOS не может проверить разработчика:
  1. Нажмите «Готово» (или «Отменить»).
  2. Откройте «Системные настройки» → «Конфиденциальность и безопасность» и нажмите «Всё равно открыть».
  3. Снова дважды щёлкните установщик.

УДАЛЕНИЕ
Дважды щёлкните «Uninstall Sakha Keyboard.command».
