# Website

Landing page at https://sakha-kb.vercel.app (Vercel project `sakha-kb`, Git-connected, production branch `main`).

- Source: `site/`: one static `index.html` + `favicon.svg`, no framework or build deps.
- `vercel.json` copies `docs/layouts/*.svg` into `site/layouts/` at build time (gitignored), so the diagrams stay generated by `build.py`.
- Preview locally: `cp -R docs/layouts site/layouts && open site/index.html`.
- Text mirrors README.md: keep install commands, flags and FAQ in sync when the README changes. The version pill reads the latest GitHub release at runtime.
