# Changelog

## [2.0.0] - 2026-10-05

### Added
- Four layouts: **Sakha (Russian)** (Windows-style number row), **Russian (Sakha)** (Opt + lookalike letter), **Sakha (Latin)** (Common Turkic) and **Sakha (Novgorodov)** (with Opt for long vowels and geminates).
- One-line installer: `curl … | bash`. It asks which layouts to add and needs no logout.
- `Sakha-Keyboard.zip` with double-click install and uninstall.
- Keyboard diagrams for every layout.

### Changed
- No layout moves or replaces a Russian or English letter.
- Layouts are generated by `build.py` instead of being edited by hand in Ukelele.

### Removed
- The v1 layouts (Sakha (Yakut), Latin and their PC variants) and the flag icons.

## [1.0.0] - 2021-11-29

- First release: Sakha (Yakut) Cyrillic and Latin layouts, each in Mac and PC variants.
