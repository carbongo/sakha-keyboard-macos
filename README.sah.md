Түөрт раскладка, биир туруоруу, перезагрузката суох:

| Раскладка | Тугар олоҕурар | Саха буукубалара ханна баалларый |
|---|---|---|
| **Sakha (Windows)** | Нуучча (Mac) | Цифра кэккэтигэр, Windows «Саха» раскладкатын курдук |
| **Sakha (Russian)** | Нуучча (Mac) | **Opt** + маарынныыр нуучча буукубата |
| **Sakha (Latin)** | US | Уопсай түүр латиницата |
| **Sakha (Novgorodov)** | US | Новгородов алпаабыта (1920-с сыллар) |

> macOS 27-гэ бэйэтин *Yakut* раскладката баар, ол эрээри кини ц, г, ъ, ф уонна ж оннуларын ылар. Бу раскладкалар туох да буукубаны солбуйбаттар.

## 🚀 Туруоруу

### 1-кы вариант: Терминал (сүбэлэнэр, сэрэтиитэ суох)

```sh
curl -fsSL https://raw.githubusercontent.com/carbongo/sakha-keyboard-macos/main/install.sh | bash
```

Скрипт ханнык раскладкалары эбэри ыйытыа; Return баттаатаххытына, **Sakha (Windows)** эрэ эбиллиэ. Раскладканы **Ctrl+Space** эбэтэр **🌐 Globe** көмөтүнэн уларытыҥ. Систематтан тахсар наадата суох.

Устуу: `… | bash -s -- -u`. Бары параметрдар: `… | bash -s -- -h`.

### 2-с вариант: Хачайдаан баран иккитэ баттааҥ

> [!WARNING]
> **Бастакы сырыыга macOS туруорааччыны бобуо.** Маннык сурук тахсыа: *«Не удалось проверить, что „Install Sakha Keyboard.command“ не содержит вредоносного ПО»*. Бу сөп. macOS Apple нотаризациятын ааспатах хачайдаммыт ханнык баҕарар скрипкэ итини көрдөрөр, оттон нотаризацияҕа төлөбүрдээх разработчик аккаунта наада. Туруорааччы — [`install.sh`](install.sh), кинини ааҕыахха сөп. Сэрэтиитэ суох туруорарга [1-кы варианы](#1-кы-вариант-терминал-сүбэлэнэр-сэрэтиитэ-суох) туттуҥ.

1. **[Sakha-Keyboard.zip](https://github.com/carbongo/sakha-keyboard-macos/releases/latest/download/Sakha-Keyboard.zip)** хачайдааҥ уонна аһыҥ.
2. **Install Sakha Keyboard.command** иккитэ баттааҥ. Сэрэтии тахсыа, «Готово» баттааҥ.
3. «Системные настройки» → «Конфиденциальность и безопасность» аһыҥ, аллара бобуллубут файл туһунан суругу булуҥ уонна «Всё равно открыть» баттааҥ. Паролунан эбэтэр Touch ID-нан бигэргэтиҥ.
4. **Install Sakha Keyboard.command** өссө иккитэ баттааҥ, «Открыть» баттааҥ уонна наадалаах раскладкаларгытын бэлиэтээҥ.

Устуу: **Uninstall Sakha Keyboard.command**. Кини туспа файл, онон кэлиэхэ эмиэ биирдэ «Всё равно открыть» хардыыта наада.

> macOS 15 уонна онтон саҥа версияларга уҥа баттааһын → «Открыть» бу сэрэтиини аһарбат. Настройкаларга «Всё равно открыть» туттуҥ.

## 🗺️ Раскладкалар

Улахан бэлиэ — клавиша бэйэтэ тугу бэчээттиирэ (Shift-тыын — улахан буукуба). Кыра розовай бэлиэ — **Opt**, үөһээ турара — **Shift+Opt**. Күөх клавишалар төрүт раскладкаттан атыннар.

### Sakha (Windows)

Windows саха раскладката (KBDYAK), Mac нуучча раскладкатыгар. ё бэйэтин клавишатыгар хаалар, цифралар — **Opt+1…0**.

![Sakha (Windows)](docs/layouts/sakha-windows.svg)

### Sakha (Russian)

Судургу Mac нуучча раскладката. **Opt** тутан туран маарынныыр саха буукубатын бэчээттиигит: г→ҕ, н→ҥ, о→ө, у→ү, х→һ, д→дь, ь→нь.

![Sakha (Russian)](docs/layouts/sakha-russian.svg)

### Sakha (Latin)

Уопсай түүр латиницата: ҕ ğ · ҥ ñ · ө ö · ү ü · ы ı · ч ç · дь j · нь ń · й y. Буукубалар бэйэлэрин клавишалаахтар, немецкэй эбэтэр турецкай клавиатураларга курдук. **Opt+буукуба** эмиэ үлэлиир (Opt+o → ö). Ол клавишалар урут бэчээттиир бэлиэлэрэ Opt-ка көһөллөр.

![Sakha (Latin)](docs/layouts/sakha-latin.svg)

### Sakha (Novgorodov)

1920-с сыллардааҕы Новгородов алпаабыта, чугас IPA буукубаларынан: ɯ ɣ ɟ ŋ ɲ ø, ч оннугар c. Дифтонг клавишалара **ie uo yø ɯa** бэчээттииллэр. **Opt+аһаҕас дорҕоон** уһун аһаҕаһы бэчээттиир (aː), **Opt+бүтэй дорҕоон** кинини хатылыыр (tt).

![Sakha (Novgorodov)](docs/layouts/sakha-novgorodov.svg)

## ❓ Ыйытыылар

<details>
<summary><b>Cmd+C / Cmd+V үлэлиэ дуо?</b></summary>

Үлэлиир. Cmd уонна Ctrl холбоһуктара бары раскладкаларга куруутун US QWERTY миэстэлэринэн үлэлииллэр.

</details>

<details>
<summary><b>Настройкаларга «Разработчик сможет получить доступ ко всему, что вы вводите» диэн суруллубут. Тугу эмэ хомуйаҕыт дуо?</b></summary>

**Суох. Туох да хомуллубат, ыытыллыбат, харайыллыбат.**

macOS 27 бу суругу Apple оҥорботох ханнык баҕарар раскладкаҕа көрдөрөр, иһигэр туох баарыттан тутулуга суох. Бу раскладкаларга код суох: `Sakha.bundle` — `Info.plist`, түөрт `.keylayout` файл («бу клавиша ҕ бэчээттиир» курдук судургу XML-таблицалар) уонна түөрт значок. Эһиги бэчээттиир кэмҥитигэр туох да үлэлээбэт. Туруорааччы биирдэ холбонор, файллары куопуйалыыр уонна бүтэр. Кини үлэлии хаалбат, хачайдааһын кэнниттэн ситимҥэ тахсыбат уонна телеметрия хомуйбат.

Бу сэрэтии киирии методтарыгар аналлаах — баттааһыннары чахчы көрөр дьиҥнээх программаларга. Apple ол тылларын судургу раскладкаларга эмиэ туттар. Бу репозиторийга бары файллар аһаҕас.

</details>

<details>
<summary><b>Меню строкатыгар значоктар тугу бэлиэтииллэрий?</b></summary>

Apple **РУ** уонна **A** курдук: **СА** — Sakha (Windows), **СР** — Sakha (Russian), **SA** — Sakha (Latin), **NV** — Sakha (Novgorodov). Рамкалаах значоктары macOS бэйэтин раскладкаларыгар эрэ уруһуйдуур, онон биһиэнэ — маҥан буукубалар. Кинилэр куруутун маҥаннар, онон сырдык меню строкатыгар көстөр уустук. Эргэ былаахтар көстө тураллар буоллаҕына, систематтан тахсан баран төттөрү киириҥ: macOS кэһин саҥардыа.

</details>
