Түөрт раскладка, биир туруоруу, перезагрузката суох:

| Раскладка | Тугар олоҕурар | Саха буукубалара ханна баалларый |
|---|---|---|
| **Sakha (Windows)** | Нуучча (Mac) | Цифра кэккэтигэр, Windows «Саха» раскладкатын курдук |
| **Sakha (Russian)** | Нуучча (Mac) | **Opt** + маарынныыр нуучча буукубата |
| **Sakha (Latin)** | US | Уопсай түүр латиницата |
| **Sakha (Novgorodov)** | US | Новгородов алпаабыта (1920-с сыллар) |

> macOS 27-гэ бэйэтин *Yakut* раскладката баар, ол эрээри кини ц, г, ъ, ф уонна ж оннуларын ылар. Бу раскладкалар туох да буукубаны солбуйбаттар.

## 🚀 Туруоруу

### 1-кы вариант: Терминал (сүбэлэнэр, сэрэтиитэ суох)

```sh
curl -fsSL https://raw.githubusercontent.com/carbongo/sakha-keyboard-macos/main/install.sh | bash
```

Скрипт ханнык раскладкалары эбэри ыйытыа; Return баттаатаххына, **Sakha (Windows)** эрэ эбиллиэ. Раскладканы **Ctrl+Space** эбэтэр **🌐 Globe** көмөтүнэн уларыт. Систематтан тахсар наадата суох.

Сотуу: `… | bash -s -- -u`. Бары параметрдар: `… | bash -s -- -h`.

### 2-с вариант: Хачайдаан баран иккитэ баттаа

> [!WARNING]
> **Бастакы сырыыга macOS туруорааччыны бобуо.** Маннык сурук тахсыа: *«Не удалось проверить, что „Install Sakha Keyboard.command“ не содержит вредоносного ПО»*. Бу сөп. macOS Apple нотаризациятын ааспатах хачайдаммыт ханнык баҕарар скрипкэ итини көрдөрөр, оттон нотаризацияҕа төлөбүрдээх разработчик аккаунта наада. Туруорааччы — [`install.sh`](install.sh), кинини ааҕыахха сөп. Сэрэтиитэ суох туруорарга [1-кы варианы](#1-кы-вариант-терминал-сүбэлэнэр-сэрэтиитэ-суох) туттун.

1. **[Sakha-Keyboard.zip](https://github.com/carbongo/sakha-keyboard-macos/releases/latest/download/Sakha-Keyboard.zip)** хачайдаа уонна ас.
2. **Install Sakha Keyboard.command** иккитэ баттаа. Сэрэтии тахсыа, «Готово» баттаа.
3. «Системные настройки» → «Конфиденциальность и безопасность» ас, аллара бобуллубут файл туһунан суругу бул уонна «Всё равно открыть» баттаа. Паролгунан эбэтэр Touch ID-нан бигэргэт.
4. **Install Sakha Keyboard.command** өссө иккитэ баттаа, «Открыть» баттаа уонна наадалаах раскладкаларгын бэлиэтээ.

Сотуу: **Uninstall Sakha Keyboard.command**. Кини туспа файл, онон кэлиэхэ эмиэ биирдэ «Всё равно открыть» хардыыта наада.

> macOS 15 уонна онтон саҥа версияларга уҥа баттааһын → «Открыть» бу сэрэтиини аһарбат. Настройкаларга «Всё равно открыть» туттун.

## 🗺️ Раскладкалар

Улахан бэлиэ — клавиша бэйэтэ тугу бэчээттиирэ (Shift-тыын — улахан буукуба). Кыра розовай бэлиэ — **Opt**, үөһээ турара — **Shift+Opt**. Күөх клавишалар төрүт раскладкаттан атыннар.

### Sakha (Windows)

Windows саха раскладката (KBDYAK), Mac нуучча раскладкатыгар. ё бэйэтин клавишатыгар хаалар, цифралар — **Opt+1…0**.

![Sakha (Windows)](docs/layouts/sakha-windows.svg)

### Sakha (Russian)

Судургу Mac нуучча раскладката. **Opt** тутан туран маарынныыр саха буукубатын бэчээттиигин: г→ҕ, н→ҥ, о→ө, у→ү, х→һ, д→дь, ь→нь.

![Sakha (Russian)](docs/layouts/sakha-russian.svg)

### Sakha (Latin)

Уопсай түүр латиницата: ҕ ğ · ҥ ñ · ө ö · ү ü · ы ı · ч ç · дь j · нь ń · й y. Буукубалар бэйэлэрин клавишалаахтар, немецкэй эбэтэр турецкай клавиатураларга курдук. **Opt+буукуба** эмиэ үлэлиир (Opt+o → ö). Ол клавишалар урут бэчээттиир бэлиэлэрэ Opt-ка көһөллөр.

![Sakha (Latin)](docs/layouts/sakha-latin.svg)

### Sakha (Novgorodov)

1920-с сыллардааҕы Новгородов алпаабыта, чугас IPA буукубаларынан: ɯ ɣ ɟ ŋ ɲ ø, ч оннугар c. Дифтонг клавишалара **ie uo yø ɯa** бэчээттииллэр. **Opt+аһаҕас дорҕоон** уһун аһаҕаһы бэчээттиир (aː), **Opt+бүтэй дорҕоон** кинини хатылыыр (tt).

![Sakha (Novgorodov)](docs/layouts/sakha-novgorodov.svg)

## ❓ Ыйытыылар

<details>
<summary><b>Cmd+C / Cmd+V үлэлиэ дуо?</b></summary>

Үлэлиир. Cmd уонна Ctrl холбоһуктара бары раскладкаларга куруутун US QWERTY миэстэлэринэн үлэлииллэр.

</details>

<details>
<summary><b>Настройкаларга «Разработчик сможет получить доступ ко всему, что вы вводите» диэн суруллубут. Тугу эмэ хомуйаҕын дуо?</b></summary>

**Суох. Туох да хомуллубат, ыытыллыбат, харайыллыбат.**

macOS 27 бу суругу Apple оҥорботох ханнык баҕарар раскладкаҕа көрдөрөр, иһигэр туох баарыттан тутулуга суох. Бу раскладкаларга код суох: `Sakha.bundle` — `Info.plist`, түөрт `.keylayout` файл («бу клавиша ҕ бэчээттиир» курдук судургу XML-таблицалар) уонна түөрт значок. Эн бэчээттиир кэмҥэр туох да үлэлээбэт. Туруорааччы биирдэ холбонор, файллары куопуйалыыр уонна бүтэр. Кини үлэлии хаалбат, хачайдааһын кэнниттэн ситимҥэ тахсыбат уонна телеметрия хомуйбат.

Бу сэрэтии киирии методтарыгар аналлаах — баттааһыннары чахчы көрөр дьиҥнээх программаларга. Apple ол тылларын судургу раскладкаларга эмиэ туттар. Бу репозиторийга бары файллар аһаҕас.

</details>

<details>
<summary><b>Меню строкатыгар значоктар тугу бэлиэтииллэрий?</b></summary>

Apple **РУ** уонна **A** курдук: **СА** — Sakha (Windows), **СР** — Sakha (Russian), **SA** — Sakha (Latin), **NV** — Sakha (Novgorodov). Рамкалаах значоктары macOS бэйэтин раскладкаларыгар эрэ уруһуйдуур, онон биһиэнэ — судургу буукубалар. Apple курдук, меню строкатын уонна меню өҥүгэр сөп түбэһэн хараҥа эбэтэр маҥан буолаллар. Эргэ былаахтар көстө тураллар буоллаҕына, систематтан тахсан баран төттөрү киир: macOS кэһин саҥардыа.

</details>
