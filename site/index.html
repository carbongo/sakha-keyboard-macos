Layouts

Pick the one that fits your hands.

Install any or all four, and switch between them from the input menu.

Sakha (Windows)

built on Mac Russian · badge СА

The Windows Sakha layout (KBDYAK), on Mac Russian. Sakha letters sit on the number row, just like on Windows. ё stays on its key, and digits move to Opt+1…0.

The default — pick this if you already type Sakha on Windows.

ҕҥөүһдьнь

Sakha (Russian)

built on Mac Russian · badge СР

Plain Mac Russian. Hold Opt for the Sakha letter that looks like it.

г→ҕн→ҥо→өу→үх→һд→дьь→нь

Sakha (Latin)

built on US · badge SA

Common Turkic Latin. The letters have their own keys, as on German or Turkish keyboards; Opt+letter works too (Opt+o → ö).

ҕ ğҥ ñө öү üы ıч çдь jнь ńй y

Sakha (Novgorodov)

built on US · badge NV

The 1920s Novgorodov alphabet, typed with the closest IPA letters. Diphthong keys type ie uo yø ɯa; Opt+vowel makes it long (aː), Opt+consonant doubles it (tt).

ɯɣɟŋɲøc = ч
differs from the base layout small legend = Opt (upper: Shift+Opt)
Install

Ready in under a minute.

Both ways install the same files to ~/Library/Keyboard Layouts.

Terminal recommended

No security warning. It asks which layouts to add — press Return for Sakha (Windows).

curl -fsSL https://raw.githubusercontent.com/carbongo/sakha-keyboard-macos/main/install.sh | bash
-l allAll four layouts, no questions
-l sakha-latin,…sakha-windows, sakha-russian, sakha-latin, sakha-novgorodov
-yDon't ask; add Sakha (Windows) only
-v v2.0.0A specific release
-uUninstall everything

Pass flags with | bash -s -- -l all.

Download and double-click

  1. Download Sakha-Keyboard.zip and open it.
  2. Double-click Install Sakha Keyboard.command. macOS warns you — click Done.
  3. Open System Settings → Privacy & Security, find the blocked installer and click Open Anyway.
  4. Double-click the installer again, click Open, and tick the layouts you want.
Why the warning? macOS flags any downloaded script that isn't notarised, which needs a paid Apple Developer account. The installer is just install.sh — read it first if you like.

To remove, run Uninstall Sakha Keyboard.command from the same zip.

FAQ

Questions, answered.

Do I really not need to log out?

No. The installer registers the bundle through macOS's Text Input Sources API, so the layouts appear immediately. Apps that were already open may pick them up only after a relaunch.

Why does macOS say it “could not verify” the installer? Is it safe?

macOS shows that for every downloaded script or app Apple hasn't notarised — it doesn't mean malware was found. The .command files only run install.sh, which copies Sakha.bundle to ~/Library/Keyboard Layouts and adds the layouts to your input menu. The Terminal one-liner shows no warning, because files fetched with curl aren't flagged as downloads.

Will ⌘C / ⌘V still work?

Yes. Cmd and Ctrl shortcuts always use the US QWERTY positions in every layout.

System Settings says “The developer can access anything you type”. Do you collect anything?

No. Nothing is collected, sent or stored. macOS 27 shows that label on every keyboard layout that doesn't come from Apple. These layouts contain no code: an Info.plist, four .keylayout XML tables and four icons. The installer runs once, copies the files and exits — no background process, no telemetry.

What do the menu bar badges mean?

Like Apple's РУ and A: СА is Sakha (Windows), СР Sakha (Russian), SA Sakha (Latin) and NV Sakha (Novgorodov). They're plain white letters, so they're hard to see on a light menu bar. If you still see old flag icons, log out and back in once.

Help shape the keyboard.

New letters, better key positions and bug reports are all welcome. The layouts are generated by build.py, so a change is usually a single line.
